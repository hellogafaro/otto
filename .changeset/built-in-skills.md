Every bot now has eleven built-in skills, shipped with Otto: research, investigate, implement, git, verify, visualize, write, handoff, summarize, close and computer. They come first in the bot's skills, git and computer only when the bot has a computer, and skill_read opens them by name. A Library skill can't take a built-in skill's name. Bots that work in git credit themselves with a co-author line.
