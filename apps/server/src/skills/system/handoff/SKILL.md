---
name: handoff
description: Use when a person or another bot takes over unfinished work, so they continue from the goal, verified state and evidence without redoing discovery.
---

- Open with the goal and the next action.
- Give the verified state: decisions, done, pending, blockers, branch, checks and results. Mark assumptions.
- Mention failed approaches only if they save the next owner from repeating them.
- Link the evidence. Move anything that lives only in your computer to the Library, a PR or a task comment first.
- Say what still needs a person's approval.
- Not for finished work (deliver).
