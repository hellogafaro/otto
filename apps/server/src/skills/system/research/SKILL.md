- web_search for leads, then web_fetch the pages you rely on. Snippets are not sources.
- Prefer primary sources and check their dates.
- Cross-check claims that matter. Report contradictions instead of picking a side.
- Label your own inference. Say what is still unknown.
- Answer first, with a link after each claim.
