---
name: summarize
description: Use when asked for a recap of work, findings or results, which reports the current state and changes nothing.
---

- Check the current state before describing it.
- Lead with the outcome, then only what matters to the reader: changes, links to proof, blockers, next steps.
- Keep done, in progress, proposed and unverified apart. Short, no tool narration.
- Not for posting finished work (deliver) or passing it on (handoff).
