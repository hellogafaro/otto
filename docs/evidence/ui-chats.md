## Unsupported controls removed and pending seams

1. Chat pin/unpin, Done/reopen, snooze, general/type/channel flags and fabricated review/working sidebar groups have no persisted operation. Removed. Decide a backend product contract before restoring them.
2. Existing Chat Project and visibility edits have no route. Their real metadata is fixed after create; creator title/archive/participants remain editable.
3. Sub-thread creation/type/parent links and structured question choices have no current Chat/Question schema. Removed mock thread cards and invented choices; saved Run questions use real free text.
4. Chat creation has no requestId/idempotency seam. A lost network/5xx creation ACK is explicit and blocks automatic retries; reader inspects actual Chats before starting another. Root may choose a future idempotent create contract.
5. Files have user/workspace visibility rather than Chat reader ACLs. Private upload remains private; attaching it to another human's audience is denied. Explicit eligible Workspace visibility is available. No automatic visibility broadening. Cancel may leave an unacknowledged saved File; library is authoritative.
6. Real provider/compute/account qualification is deferred. Run controls/admission are wired; fixtures prove only exercised compute/storage contracts. No native-host/account/model/billing fallback.
7. Shared directory, avatars, mentions, Composer, file upload helper and router are integration dependencies. Root installs the exported Chats landing/URL validator and owns final browser evidence and DESIGN.md integration.

## Design decisions for root integration into DESIGN.md

Keep the existing sidebar/thread/Message/Bubble/Scroller/composer/floating-window composition and animation. Show active/archived Chat discovery with metadata sorting instead of unsupported pin/done/snooze state. New Chat begins without a fabricated selected Agent; participant/Project/visibility are compact stock pickers. Creator title editing uses a stock Dialog. The right panel adds explicit Run admission with Agent, type, private Session and bounded execution-content selections. Real Run activity and free-text questions use existing Collapsible/Marker/Card primitives. Attachment scope is an explicit stock picker defaulting to Only me, with the audience limitation stated before upload; Files open through authorized verified download. No shared component look changes were made by this lane.
